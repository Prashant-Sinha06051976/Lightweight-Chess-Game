
# Lightweight Dynamic Chess AI

Optimized deployment-ready multiplayer chess platform.

## Features
- Play vs AI
- Online Multiplayer
- Full Chess Rules
- Advanced Analytics
- Move Suggestions
- Lightweight Deployment

## IMPORTANT
Do NOT upload:
- venv/
- engine/
- __pycache__/

## Install

```bash
pip install -r requirements.txt
```

## Download Stockfish

Download separately from:
https://stockfishchess.org/download/

Put executable inside:

```text
engine/stockfish.exe
```

## Run Backend

```bash
python server.py
```

## Run Frontend

```bash
streamlit run app.py
```
